# Results data

This directory holds the per-window analysis tables produced by the real-data
audit, one per dataset:

- `real_data/wesad_deep/window_table.csv` (WESAD, 6,585 windows)
- `real_data/ppg_dalia/window_table.csv` (PPG-DaLiA, 18,781 windows)

Both tables share the same 19 columns. Each row is one analysis window: a fixed
5-second segment of wrist PPG with its time-aligned chest-ECG reference. Every
window carries the in-house quality scores and the verdicts and underlying
features of the three published signal-quality methods audited in the paper
(Orphanidou 2015, Sukor 2011, Elgendi 2016).

## Columns

| Column | Type | Description |
| --- | --- | --- |
| `window_idx` | int | Sequential index of the window. |
| `subject_id` | str | Subject identifier (for example `S10`). |
| `label` | int | Numeric code for the task or condition during the window. |
| `label_name` | str | Condition name (for example `baseline`, `sitting`). |
| `hr_ecg` | float | Reference heart rate from chest ECG, in bpm. Missing when no reliable ECG heart rate could be computed for the window. |
| `hr_ppg` | float | Heart rate estimated from wrist PPG, in bpm. |
| `hr_abs_diff` | float | Absolute difference between `hr_ppg` and `hr_ecg`, in bpm. Missing wherever `hr_ecg` is missing. |
| `inhouse_ecg_sqi` | float | In-house ECG signal-quality score in [0, 1]. |
| `inhouse_ppg_sqi` | float | In-house PPG signal-quality score in [0, 1]. The single fixed in-house threshold studied in the paper accepts a window when this value is at least 0.70. |
| `inhouse_ppg_motion` | float | In-house PPG motion metric for the window. |
| `orphanidou_acceptable` | int (0/1) | Orphanidou 2015 verdict: 1 if the window is accepted, 0 if rejected. |
| `orphanidou_template_corr` | float | Template-matching correlation that the Orphanidou method thresholds. |
| `sukor_acceptable` | int (0/1) | Sukor 2011 verdict: 1 if accepted, 0 if rejected. |
| `sukor_pp_cv` | float | Peak-to-peak interval coefficient of variation used by the Sukor method. |
| `sukor_amp_cv` | float | Pulse-amplitude coefficient of variation used by the Sukor method. |
| `elgendi_acceptable` | int (0/1) | Elgendi 2016 verdict: 1 if accepted, 0 if rejected. |
| `elgendi_skewness` | float | Skewness statistic used by the Elgendi method. |
| `elgendi_kurtosis` | float | Kurtosis statistic used by the Elgendi method. |
| `elgendi_entropy` | float | Signal entropy used by the Elgendi method. |

## Derived quantities

Consensus rejection, the headline of the paper, is the set of windows that all
three published methods reject at the same time:

    consensus_reject = (orphanidou_acceptable == 0)
                     & (sukor_acceptable == 0)
                     & (elgendi_acceptable == 0)

On WESAD this is 2,935 of 6,585 windows (44.6%); on PPG-DaLiA it is 8,100 of
18,781 (43.1%). The test `tests/test_paper_headline_numbers.py` recomputes these
counts from these tables, and Figure 1 (`paper/figures/fig1_upset.py`) draws the
full acceptance structure.

The cross-modality heart-rate analysis (Figure 2) uses the subset of windows
that have both `hr_ecg` and `hr_ppg`. On WESAD, 16 windows lack an ECG reference,
leaving 6,569 paired windows; on PPG-DaLiA, 391 lack one, leaving 18,390.

## Provenance

These tables are generated by the WESAD and PPG-DaLiA analysis scripts in
`scripts/` from the public source datasets and are not hand-edited. Reproduction
commands for the tables and figures are collected in `paper/REPRODUCE.md`.
